## 二、每日工作流

```
1. 拉取最新代码
   git stash -u → git pull → git stash pop

2. 启动服务
   后端：IDEA 运行 RuoYiApplication
   前端：cd ruoyi-ui → npm run dev

3. 开发
   写 Controller → 编译验证 → 接口自测

4. 提交
   Ctrl+K → 只勾业务文件 → commit → Ctrl+Shift+K push

5. 拉取检查
   同事推了新代码 → stash → pull --rebase → stash pop → push
```

## 三、接口开发标准流程

```
1. 需求分析
   → 确定哪些接口给运营端，哪些给小程序端
   → 确定入参出参

2. 看 Service 层
   → 现有 Service 有哪些方法可复用
   → 不够的要不要补

3. 写 Controller
   → 运营端：/api/v1/ops/* + @PreAuthorize
   → 小程序端：/api/v1/* + @Anonymous
   → 加 @Schema/@Operation 文档

4. 编译验证
   mvn -pl ruoyi-admin -am compile -q

5. 接口自测
   → 新增 → 查询 → 修改 → 删除 闭环

6. 提交推送
   → 只提交业务文件
   → commit message 写清楚改了什么

7. 通知前端
   → 发接口地址 + Swagger 链接
   → 切 loop-v1 分组
```
