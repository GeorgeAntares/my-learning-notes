### 端口分配 / Port Allocation

| 端口 Port | 服务 Service | 启动方式 Startup Method |
|------|------|------|
| 8080 | 后端 Backend | IDEA 运行 RuoYiApplication / Run in IDEA |
| 80 | 运营端前端 Ops frontend | `npm run dev`（在 ruoyi-ui / in ruoyi-ui） |

**重要 Important**：前端（80）和后端（8080）是独立进程，重启一个不会自动启动另一个。

Frontend (80) and backend (8080) are independent processes. Restarting one does not start the other.

## 三、启动流程 / Startup Process

### 完整启动顺序 / Full Startup Order

```
1. 启动 MySQL 和 Redis（通常已在服务器上运行）
   Start MySQL and Redis (usually already running on server)

2. 启动后端 / Start backend
   IDEA → 运行 RuoYiApplication
   IDEA → Run RuoYiApplication
   看到 "Started RuoYiApplication" 表示成功
   "Started RuoYiApplication" = success

3. 启动运营端前端 / Start ops frontend
   cd <your-project-path>/ruoyi-ui
   npm run dev
   看到 "App running at: http://localhost:80" 表示成功

4. 访问 / Access
   运营端 Ops: http://localhost:80
   Swagger: http://localhost:8080/swagger-ui.html (切 loop-v1 分组 / switch to loop-v1)
```

### 小程序端启动 / Mini-Program Startup

```
1. 安装依赖 / Install dependencies
   cd <mini-program-dir>
   npm install  (场馆端用 / venue uses: npm install --legacy-peer-deps)

2. 运行到微信开发者工具 / Run in WeChat DevTools
   npm run dev:mp-weixin

3. 微信开发者工具导入 dist 目录 / Import dist in DevTools
   详情 → 本地设置 → 勾选"不校验合法域名"
   Details → Local Settings → Check "Do not verify domain"
```

## 四、配置文件 / Configuration Files

### application.yml 关键配置 / Key Config

> **注意 Note**：以下为配置模板，请替换为实际地址和凭据。
> The following is a config template. Replace with actual addresses and credentials.

```yaml
# 数据库 / Database
spring:
  datasource:
    url: jdbc:mysql://<db-host>:<db-port>/<db-name>
    username: <username>
    password: <password>

# Redis
  redis:
    host: <redis-host>
    port: 6379

# 端口 / Port
server:
  port: 8080
```

### 前端代理配置 / Frontend Proxy Config

`vue.config.js` 中配置代理：

Configure proxy in `vue.config.js`:

```javascript
devServer: {
  port: 80,
  proxy: {
    '/dev-api': {
      target: 'http://localhost:8080',
      changeOrigin: true,
      pathRewrite: { '^/dev-api': '' }
    }
  }
}
```

前端请求 `/dev-api/api/v1/ops/notice` → 代理到 → `http://localhost:8080/api/v1/ops/notice`

## 五、网络环境变化 / Network Environment Changes

### IP 变化问题 / IP Change Issue

每次重连 WiFi 后，本机 IP 可能变化，需要同步更新：

IP may change after reconnecting WiFi. Update in:

| 文件 File | 更新内容 What to update |
|------|------|
| 小程序 utils/config.js | BASE_URL 改为新 IP / Update to new IP |
| application.yml | 如果数据库/Redis IP 变了也要改 / If DB/Redis IP changed |

### 查看本机 IP / Check Local IP

```powershell
ipconfig
# 找 IPv4 地址 / Find IPv4 address
```

## 六、安全配置（临时调试用）/ Security Config (Temporary Debug)

### 当前调试模式 / Current Debug Mode

开发期间临时关闭了权限检查：

Permission checks temporarily disabled during development:

```java
// SecurityConfig.java
.anyRequest().permitAll()    // 允许所有请求 / Allow all requests

// RuoYiApplication.java
@EnableMethodSecurity(prePostEnabled = false)  // 关闭方法级权限 / Disable method security
```

### 上线前必须恢复 / Must Restore Before Production

| 文件 File | 恢复为 Restore to |
|------|------|
| SecurityConfig.java | `.anyRequest().authenticated()` |
| RuoYiApplication.java | `@EnableMethodSecurity(prePostEnabled = true)` |

**注意 Note**：这两个改动不应提交到仓库，只在本地调试用。

These changes should NOT be committed to the repository. For local debugging only.

## 七、数据库初始化 / Database Initialization

SQL 脚本在 `sql/` 目录下，按顺序执行：

SQL scripts in `sql/` directory, execute in order:

```

├── ry_20260417.sql                    → 1. RuoYi 基础表 / Base tables
├── loop/
│   ├── V001__init.sql                 → 2. LOOP 初始化 / LOOP init
│   ├── V002__venue.sql                → 3. 场馆表 / Venue tables
```

Flyway automatically detects and runs unexecuted scripts.
