## 二、复杂度分析 / Complexity Analysis

### 时间复杂度 / Time Complexity

用大 O 表示法描述算法运行时间随输入规模的增长趋势。

Use Big O notation to describe how runtime grows with input size.

| 复杂度 Complexity | 名称 Name | 示例 Example | n=10 时的操作数 Operations at n=10 |
|------|------|------|------|
| O(1) | 常数 Constant | 数组取值 Array access | 1 |
| O(log n) | 对数 Logarithmic | 二分查找 Binary search | 4 |
| O(n) | 线性 Linear | 遍历数组 Traverse array | 10 |
| O(n log n) | 线性对数 Linearithmic | 归并排序 Merge sort | 33 |
| O(n²) | 平方 Quadratic | 冒泡排序 Bubble sort | 100 |
| O(2ⁿ) | 指数 Exponential | 递归斐波那契 Recursive Fibonacci | 1024 |

**排序 Sorting**：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)

### 空间复杂度 / Space Complexity

描述算法额外使用的内存空间。

Describes extra memory used by the algorithm.

| 复杂度 Complexity | 示例 Example |
|------|------|
| O(1) | 原地排序 In-place sort |
| O(n) | 创建新数组 Create new array |
| O(n²) | 二维矩阵 2D matrix |

## 三、基础数据结构 / Basic Data Structures

### 1. 数组 Array

```java
// 特点 Features:
// - 内存连续 Contiguous memory
// - 查找 O(1) Access O(1)
// - 插入/删除 O(n) Insert/Delete O(n)

int[] arr = {1, 2, 3, 4, 5};
int value = arr[0];       // O(1) 查找 / Access
arr[0] = 10;              // O(1) 修改 / Update

// 插入需要移动元素 / Insert requires shifting
// [1,2,3,4,5] → 在位置1插入0 → [1,0,2,3,4,5]
```

### 2. 链表 Linked List

```java
// 特点 Features:
// - 内存不连续 Non-contiguous memory
// - 查找 O(n) Access O(n)
// - 插入/删除 O(1) Insert/Delete O(1)（已知位置时 / if position known）

class ListNode {
    int val;
    ListNode next;
    ListNode(int val) { this.val = val; }
}

// 单链表遍历 / Singly linked list traversal
ListNode curr = head;
while (curr != null) {
    System.out.println(curr.val);
    curr = curr.next;
}
```

### 3. 栈 Stack

```java
// 特点 Features:
// - 后进先出 LIFO (Last In First Out)
// - 压入 O(1) Push O(1)
// - 弹出 O(1) Pop O(1)

Stack<Integer> stack = new Stack<>();
stack.push(1);    // 压入 / Push
stack.push(2);
stack.push(3);
int top = stack.pop();   // 弹出3（最后的）/ Pop 3 (last pushed)
int peek = stack.peek(); // 查看栈顶2（不弹出）/ Peek 2 (no pop)
```

**应用场景 Use Cases**：函数调用栈 Function call stack、括号匹配 Bracket matching、撤销操作 Undo

### 4. 队列 Queue

```java
// 特点 Features:
// - 先进先出 FIFO (First In First Out)
// - 入队 O(1) Enqueue O(1)
// - 出队 O(1) Dequeue O(1)

Queue<Integer> queue = new LinkedList<>();
queue.offer(1);   // 入队 / Enqueue
queue.offer(2);
queue.offer(3);
int front = queue.poll();  // 出队1（最先的）/ Dequeue 1 (first added)
```

**应用场景 Use Cases**：BFS 广度优先搜索、任务队列 Task queue、消息队列 Message queue

### 5. 哈希表 Hash Map

```java
// 特点 Features:
// - 键值对存储 Key-value storage
// - 查找/插入/删除 O(1) 平均 Average O(1)
// - 最坏 O(n) Worst case O(n)

Map<String, Integer> map = new HashMap<>();
map.put("apple", 5);       // 插入 / Put
map.put("banana", 3);
int count = map.get("apple");  // 查找 O(1) / Get O(1)
map.remove("banana");      // 删除 / Remove

// 遍历 / Iterate
for (Map.Entry<String, Integer> entry : map.entrySet()) {
    System.out.println(entry.getKey() + ": " + entry.getValue());
}
```

### 6. 树 Tree

```java
// 二叉树 Binary Tree
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
    TreeNode(int val) { this.val = val; }
}

// 遍历方式 Traversal Methods:
// 前序 Pre-order:  根 → 左 → 右  Root → Left → Right
// 中序 In-order:   左 → 根 → 右  Left → Root → Right
// 后序 Post-order: 左 → 右 → 根  Left → Right → Root

void preOrder(TreeNode root) {
    if (root == null) return;
    System.out.println(root.val);   // 根 Root
    preOrder(root.left);            // 左 Left
    preOrder(root.right);           // 右 Right
}
```

## 四、基础算法 / Basic Algorithms

### 1. 排序 Sorting

#### 冒泡排序 Bubble Sort — O(n²)

```java
// 每轮把最大值"冒泡"到最后
// Each round bubbles the largest to the end
void bubbleSort(int[] arr) {
    for (int i = 0; i < arr.length - 1; i++) {
        for (int j = 0; j < arr.length - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

#### 快速排序 Quick Sort — O(n log n)

```java
// 选基准，小于基准的放左边，大于的放右边，递归
// Pick pivot, smaller goes left, larger goes right, recurse
void quickSort(int[] arr, int low, int high) {
    if (low < high) {
        int pivot = partition(arr, low, high);
        quickSort(arr, low, pivot - 1);
        quickSort(arr, pivot + 1, high);
    }
}

int partition(int[] arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            int temp = arr[i]; arr[i] = arr[j]; arr[j] = temp;
        }
    }
    int temp = arr[i + 1]; arr[i + 1] = arr[high]; arr[high] = temp;
    return i + 1;
}
```

### 2. 查找 Search

#### 二分查找 Binary Search — O(log n)

```java
// 前提：数组已排序 / Prerequisite: sorted array
int binarySearch(int[] arr, int target) {
    int left = 0, right = arr.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] == target) return mid;
        else if (arr[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;  // 未找到 / Not found
}
```

### 3. 递归 Recursion

```java
// 斐波那契数列 Fibonacci Sequence
// F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)
int fibonacci(int n) {
    if (n <= 1) return n;          // 基线条件 Base case
    return fibonacci(n - 1) + fibonacci(n - 2);  // 递归 Recursive case
}
// 注意：递归 fib 的时间复杂度是 O(2ⁿ)，实际可用动态规划优化到 O(n)
// Note: Recursive fib is O(2ⁿ), can be optimized with DP to O(n)
```
